# ADR-007: Boundary-Region Tolerance Band

**Status:** obsolete (2026-10-04)

The moisture-threshold boundary analysis this ADR parameterized no longer exists: labels come from the `copra_class` column (owner's pasa grade), with no per-sample moisture reading (`model-development-instructions.md` §3). The only moisture data is six pooled Brown-Duvel readings checked against grade bands (§9, acceptance L1); boundary values go to the higher grade (`docs/classes.md`). Kept for history.
